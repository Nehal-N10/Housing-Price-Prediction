# Housing Price Prediction System
A machine learning–based property valuation system that predicts house prices based on multiple property features.  
The project integrates **data preprocessing, XGBoost regression, and a Flask-based web application** to provide accurate and real-time house price predictions.

# Project Overview
Accurately estimating house prices is a major challenge in the real estate industry due to multiple influencing factors such as location, size, construction year, and amenities.
Traditional manual valuation methods often suffer from subjectivity and inconsistency. This project provides a data-driven, automated, and reliable solution for predicting housing prices using historical data and machine learning techniques.

# Problem Statement
Manual house price estimation often leads to:
- Inconsistent pricing
- Subjective bias
- Pricing errors affecting buyers and sellers

There is a need for a system that can:
- Analyze multiple property attributes
- Provide instant and accurate price estimates
- Offer a user-friendly interface for real-world usage

# Solution Approach
The system implements a complete machine learning pipeline:
- Data preprocessing and cleaning
- Feature engineering and selection
- Model training using **XGBoost Regressor**
- Backend API development using **Flask**
- Frontend interface using **HTML, CSS, and JavaScript**

# Algorithm Used
- XGBoost Regressor

# Why XGBoost?
- Handles non-linear relationships efficiently
- Performs well on structured/tabular data
- Outperformed other tested models

# Model Performance
 -R² Score: ~84.7%
- Indicates strong predictive accuracy

# How to Use the Application
-Open the web interface
-Fill in the property details
-Click Predict Value
-View the estimated house price instantly

# Output
-Predicted house price
